# Synthetic ERP → General Ledger Simulator

## Overview

This project generates **fully synthetic ERP-style financial data** and demonstrates how operational activity flows into a **balanced General Ledger (GL)**.

The objective is to create **realistic, auditable financial datasets** without using or distributing any proprietary data, while preserving core accounting constraints such as debit/credit balance and traceability from source events to GL journals.

This repository explores the design of an ERP-style data generation pipeline, with an emphasis on accounting correctness, traceability, and downstream analytics.

## What This Project Does

- Generates synthetic **master data** (starting with employees)
- Simulates **operational subledger activity** (starting with payroll)
- Posts subledger events into a **balanced General Ledger**
- Produces clean, reproducible datasets suitable for analytics and ML experimentation

Additional subledgers and analytics will be added incrementally.
